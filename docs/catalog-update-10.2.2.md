# Catalog refresh for 10.2.2

Reviewed November 22, 2026 for client 10.2.2, Steam build 25975710, and backend 10.2.2b. The same catalog inputs are used for both tracker hosts.

| Tracker category | Coverage | Changes |
| --- | --- | --- |
| Perks | 321 | Updated 60 summaries and their tier data from live balance notes and build evidence. Existing licensed aliases and save IDs are retained. |
| Survivor items | 38 | Checked existing stock records against the client build and corrected display names. |
| Survivor add-ons | 54 | Checked regular stock membership and corrected Refined Serum's Haste duration to 20 seconds. |
| Killer add-ons | 880 | Checked owner matches, corrected 31 display names, and corrected the rarities of Tampered Timer and Rule Set No.2. |
| Killer powers | 44 | Applied the official Executioner and Good Guy tuning and documented the Mastermind's Virulent Bound updates. |

The stock catalog covers inventory that the tracker can record. Match-only items, retired records outside the existing inventory, maps, and offerings have no current tracker inventory surface. Blight Serum remains historical in the research data and outside the active Killer add-on list.

For the powers affected by backend tuning, the official notes supply values the client descriptions omit. The existing effects for Odd Bulb, Manna Grass Braid, Potion of Speed, Shiawase Amulet, and Compound Twenty-One were retained where the display tooltip and other gameplay references disagree or use different units. Seasonal stock entries retain their existing tracking labels. Those labels describe stored inventory rather than current event acquisition.
